# Simple Python Command-Line Interfaces

- `main_input.py`: Prompts the user for input using the `input` command.
- `main_sys.py`: Old-school command line parsing. Not really recommended, just a peek under the hood.
- `main_argparse.py`: Better way, using the `argparse` library. Comes with a lot of built-in functionality and handles much of the parsing/validation for you.

You'd likely want to use some combination of the input and/or argparse versions for most applications.
